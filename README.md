# CoreScreen

**CoreScreen** es un launcher minimalista para Android enfocado en la simplicidad, la ausencia de ruido visual y una interfaz fluida. Diseñado para ofrecer una experiencia limpia y esencial desde el primer toque.

## ✨ Características Principales
- **Pantalla de Bloqueo Minimalista:** Saludo personalizado, fecha limpia y un reloj analógico elegante y sin números.
- **Reloj Analógico Personalizado (`MinimalAnalogClockView`):** Componente gráfico optimizado con manecillas suaves y un segundero sutil.
- **Diseño Monocromático:** Estética oscura de alto contraste adaptada para la máxima sencillez visual.
- **Rendimiento Ligero:** Sin distracciones, widgets pesados o elementos innecesarios.

## 🛠️ Tecnologías
- **Lenguaje:** Kotlin
- **Plataforma:** Android (Vistas personalizadas con `Canvas`, Activities, Intents)
- **Control de Versiones:** Git / GitHub
